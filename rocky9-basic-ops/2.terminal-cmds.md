### 终端命令

## 1.基础篇
# ls                                             列出目录里面的文件和文件夹(list)
# su                                             切换用户(swich user)
su root                                        #切换到 root 用户，但不加载 root 完整环境变量
su - root/su - (后者默认切 root)                #"-" 代表完全切换用户(切换身份 + 加载该用户全部环境变量、进入用户家目录)
su - "用户名"                                   #切换至指定普通用户
# cd                                              切换目录，进入/退出文件夹(change directory)
cd + 文件夹名         # 进入指定文件夹
cd + ..              # 返回上一级文件夹（..代表上级目录）
cd + ~               # 回到当前用户的家目录
cd + /               # 直接进入根目录

## 2.创建文件
# touch + 文件名                    本意是修改文件时间戳；如果文件不存在，就直接新建一个空文件。
示例：touch test.txt
# echo + "文本" + > + 文件名        创建文件 + 直接写入文字(如果文件不存在：新建；文件存在：覆盖原有全部内容)
示例：echo "hello rocky" > hello.txt
# cat + > + 文件名                  创建文件，然后手动输入多行内容(敲完回车，你就可以打字写内容；写完按 Ctrl + D 保存退出)
示例：cat > note.txt
示例：cat test.txt                  #查看文件里面内容
# mkdir + 文件名                    创建文件夹
示例：mkdir mydir
示例：mkdir -p a/b/c                #递归创建多层目录，父目录不存在也能一次性建好
# mv(move)                         既可以改名，也可以移动文件
示例：mv old.txt new.txt            #同目录改名
示例：mv olddir newdir              #给文件夹改名（目录也能用 mv，不用加 - r）
示例：mv test.txt ~/lab/demo.txt    #移动 + 一次性改名（跨文件夹），把 test.txt 移动到~/lab目录，同时改名叫 demo.txt
示例：mv -i old.txt new.txt         #-i如果新名字文件已经存在，会询问你是否覆盖（y/n）
示例：mv -v old.txt new.txt         #-v显示执行过程

## 3.删除(remove)
# rm + 文件名                       删除单个文件
示例：rm test.txt
示例：rm -i test.txt
示例：rm -v test.txt
# rm -r mydir                      删除文件夹
示例：rm -r mydir                   
示例：rm -ri mydir
示例：rm -rv mydir
示例：rm -rf mydir                  #强制删除，不提示（高危！生产慎用）！！！
