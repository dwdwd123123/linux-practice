# vim
vim 是 vi 增强版，vi 基础命令两者通用，掌握 vim 即掌握 vi；
vim 独有的增强功能（多步撤销、语法高亮、分屏）

vim test.txt            #若存在则打开文件，若不存在则创建并打开需要保存，可用Tab键补全文件名

## 1.普通模式（Normal，默认进入）
打开 vim 直接进入。不能直接打字，所有按键都是命令：移动光标、删除、复制、粘贴
任何其他模式，按Esc都回到普通模式

## 2.插入模式（Insert，打字编辑）
普通模式下，按如下快捷键进入，可以输入文字。左下角会出现 -- INSERT --
i：在光标前面插入（最常用）
a：在光标后面插入
o：在当前行下方新开一行，直接进入编辑
I：跳到行首开始输入
A：跳到行尾开始输入
O：在当前行上方新开一行
写完文字，一定要按 Esc，退回普通模式，才能执行保存退出

## 3.底行模式（末行模式，保存 / 退出 / 全局操作）
普通模式下，按 :（Shift+;），左下角出现冒号，输入命令回车执行。
:w                 保存，不退出 vim
:q                 退出，文件没修改才能退出，改了内容直接 q 会报错 
:wq / :x           保存并退出（最常用）
:q!                不保存，强制退出，修改全部丢弃 
:w!                强制保存（只读文件，需要 root 权限）
:set nu            显示行号，方便看配置文件 
:set nonu          关闭行号 
/关键词             普通模式直接输入/xxx，向下搜索文字；n 下一个匹配，N 上一个 

#### 普通模式快捷键（Esc之后才能用）
# 光标移动
gg        # 跳到文档开头
G         # 跳到文档末尾
$         # 跳到行尾
^         # 跳到行首

# 删除
x         # 删除光标单个字符
dd        # 删除当前一整行
3dd       # 删除光标起往下3行

# 复制粘贴
yy        # 复制当前一行
3yy       # 复制3行
p         # 粘贴到光标下一行
u         # 撤销上一步操作
