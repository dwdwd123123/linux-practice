# Rocky9 根目录笔记
- `/usr`             存放用户程序(如/bin和/sbin)、文档、库(如/lib和/lib64)，是系统软件大本营
- `/bin`             基础可执行命令（binary 二进制程序）
- `/sbin`            管理员(root)专用系统命令
- `/boot`            系统启动相关文件、内核
- `/dev`             设备文件（硬盘、网卡等硬件抽象）
- `/etc`             系统配置文件
- `/home`            普通用户家目录
- `/lib /lib64`      系统库文件
- `/media`           可移动介质挂载点（如U 盘和光驱）
- `/mnt`             临时手动挂载目录
- `/opt`             第三方大型软件安装目录
- `/proc`            虚拟文件系统，内核 / 进程信息
- `/root`            root 超级管理员家目录
- `/run`             运行时临时数据
- `/srv`             系统服务存放数据
- `/sys`             系统硬件内核信息
- `/tmp`             临时文件目录
- `/var`             可变数据（日志、缓存）
